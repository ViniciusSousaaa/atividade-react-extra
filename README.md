# Atividade React - Desafio Extra

Mesma aplicação da atividade principal, com gerenciamento de estado global usando Context API para as notificações (Toast).

## Componentes

- Acordeão
- Paginação
- Barra de Progresso
- Abas
- Menu Suspenso
- Notificação Toast

## Como rodar

npm install
npm run dev
